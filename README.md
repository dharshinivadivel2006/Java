House Rental System

Abstract
The House Rental System is a Java-based application used to manage house rental details. It helps users add, view, search, and rent houses easily.

Problem Statement
Finding and managing rental houses manually takes time and effort. This system makes house rental management simple and easy.

Objectives
- To add house details.
- To view available houses.
- To search houses by location.
- To rent available houses.
- To check house availability.

Technologies Used
- Programming Language: Java
- Concepts: Class, Object, ArrayList, Methods
- IDE: Visual Studio Code

Modules
1. Add House
2. View Houses
3. Search House
4. Rent House
5. Exit

Working Principle
The system stores house details using an ArrayList. Users can search for houses and rent available houses. Once a house is rented, its status changes to unavailable.

Conclusion
The House Rental System provides a simple way to manage rental house information using Java programming concepts.
